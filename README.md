# Convex Quadratic Programming Solver

A research-oriented Python implementation of a primal-dual interior-point solver for convex quadratic programming.

## Features
- Convex QP formulation
- Primal-dual interior-point method
- Mehrotra predictor-corrector
- KKT systems
- Numerical linear algebra
- Validation and benchmarking
